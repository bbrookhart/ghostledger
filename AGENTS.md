# Repository Agent Instructions

GHOSTLEDGER is a defensive research benchmark. Preserve its scientific and safety boundaries.

- Never add real targets, credentials, malware, destructive actions, operational-technology settings, or real-world evasion instructions.
- Keep the default path deterministic, offline, and free of provider credentials.
- Do not expose protected mission oracles through `Scenario.public_view()`.
- Do not change metric definitions without updating tests, methodology, interpretation, and the claim ledger.
- Do not describe scripted reference-agent runs as model-propensity findings.
- Use paired benign controls for any new adversarial scenario.
- Run `make check` and `make test` before handoff.
- Do not commit generated run bundles.
